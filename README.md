# SFI // BLACK CHRONICLE

Защищённый посмертный архив Объекта №12 — Уильяма. Проект рассказывает о катастрофе борта SFI-17K, двадцати одном дне в мире мёртвых, извлечении личности комплексом «Архив» и протоколе закрытия связки «тело — Тень».

## Локальный запуск GitHub Pages-версии

```bash
python -m http.server 8080 --directory site
```

## Обновление закрытого текста

Незашифрованный канон хранится только локально в `private-content/archive.json` и исключён из Git.

```bash
SFI_ARCHIVE_PASSWORD='новый-ключ' node scripts/encrypt-archive.mjs private-content/archive.json site/secure/archive.enc.json
```

## Проверка

Публикация выполняется автоматически из каталога `site` после обновления ветки `main`.

Сайт адаптирован для настольных и мобильных экранов. Открытый репозиторий содержит только интерфейс, иллюстрации и зашифрованный архив.
