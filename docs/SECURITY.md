# Защита архива

Содержимое хроники не входит в открытый клиентский код. Оно хранится в `assets/secure/archive.enc.json` как шифротекст AES-256-GCM. Ключ получается локально из введённого пароля через PBKDF2-SHA-256 с 310 000 итераций.

Исходный незашифрованный файл находится в локальном каталоге `private-content` и исключён из Git. После ввода правильного ключа браузер расшифровывает данные только в памяти текущей вкладки. Ключ не сохраняется в `localStorage` или `sessionStorage`.

Статический сайт не может обеспечить серверную авторизацию. Сильное шифрование скрывает содержимое от обычного просмотра репозитория, но стойкость защиты всё равно зависит от сложности пароля.
